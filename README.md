# AI Smart Inventory System

## Project Description
AI Smart Inventory System is a web-based application
designed to manage products, stock quantities, sales,
and inventory reports.

## Objectives
- Manage product details.
- Monitor stock quantities.
- Record sales information.
- Identify low-stock products.
- Generate inventory reports.
- Provide basic inventory recommendations.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Project Modules
1. Login Page
2. Dashboard
3. Product Management
4. Sales Management
5. Inventory Reports
6. Database Connection

## Files Used
- index.html
- style.css

- dashboard.html
- products.html

- reports.html
- db.php
- products.php
- README.md

## Database
Database Name: inventory_db

The database and products table must be created
on a server that supports PHP and MySQL.
